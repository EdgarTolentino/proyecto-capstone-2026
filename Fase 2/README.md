# Fase 2 — Desarrollo (S5–S15)

Evaluación de avance en **S10**. Entrega final del sistema en **S15**.

## Qué se entrega en esta fase

| Entregable | Dónde | Responsable |
|---|---|---|
| Sistema completo (web + base de datos + algoritmos) | [`sistema/`](sistema/) | Equipo |
| Documentos de diseño: arquitectura, GUI, modelo de datos | [`docs/`](../docs/) | Edgar / Frontend |
| Documentos de control y pruebas | `Evidencias Grupales/` | Equipo |
| Informe de avance S10 | `Evidencias Grupales/` | Equipo |
| Bitácora individual | `Evidencias Individuales/` | Cada uno |

## El código

Todo el desarrollo vive en [`sistema/`](sistema/). Ese directorio es la raíz técnica del
proyecto: paquetes, pruebas, contenedores y configuración. Se trabaja con ramas y Pull
Requests, nunca empujando directo a `main`.
