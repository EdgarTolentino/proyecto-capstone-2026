# Evidencias Proyecto — Fase 2

Las evidencias del **producto** (distintas de las evidencias de proceso del equipo y de cada
integrante).

- `Evidencias de documentacion/` — manuales, diseño de interfaz, modelo de datos, plan y
  resultados de pruebas.
- `Evidencias de sistema/Aplicacion/` — puntero a [`../../sistema/`](../../sistema/), la versión
  entregada y su etiqueta de git.
- `Evidencias de sistema/Base de datos/` — script del esquema, diagrama entidad-relación,
  respaldo y juego de datos de ejemplo.
